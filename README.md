# ShopEase — React E-commerce Store

A responsive frontend portfolio project built with React and Vite.

## Features
- Product grid and category filters
- Product search
- Sort by featured, price, and rating
- Add to cart, remove items, and change quantity
- Cart persists in localStorage
- Favorites toggle
- Responsive layout for desktop and mobile
- Demo checkout and newsletter form

## Run locally
1. Install Node.js (LTS recommended).
2. Extract this folder and open it in VS Code.
3. Open a terminal in this project folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL shown in the terminal, usually `http://localhost:5173`.

## Notes
This is a frontend demo. It does not include a backend, real authentication, inventory management, order processing, or payment integration. The checkout button is intentionally a demo.
